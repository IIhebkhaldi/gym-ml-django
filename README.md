# Gym ML — Application web Django et Machine Learning

Projet associant une application web Django et des modèles de Machine Learning appliqués à des données liées à une salle de sport.

## Objectif
Exploiter des données pour produire des analyses et intégrer des fonctionnalités prédictives dans une application web.

## Contenu
- `ML_PR.ipynb` : expérimentations de Machine Learning.
- `GUIDE_COMPLET_CREATION_PROJET.md` : guide détaillé du projet.
- `RAPPORT_VERIFICATION_MODELES.md` : vérification des modèles.
- `RAPPORT_VERIFICATION_COMPATIBILITE.md` : contrôles de compatibilité.
- `CHANGEMENTS_CSS.md` : documentation des modifications d'interface.

## Technologies
Python, Django, Jupyter Notebook, Machine Learning, HTML et CSS.

## Installation
Consulter `GUIDE_COMPLET_CREATION_PROJET.md` pour les prérequis et les étapes adaptées à la structure de l'application.
